# Midhunam Pure Veg — Simple HTML Website

This is a plain HTML/CSS/JavaScript website. It does NOT use React, Next.js, npm, Node.js or a build step.

## Run it
1. Extract the ZIP.
2. Open the `midhunam-static-site` folder.
3. Double-click `index.html` (or right-click → Open with → Chrome).

Keep the `images` folder next to `index.html`; the page loads the three supplied image files from there.

## Publish it
Upload `index.html` and the `images` folder to any static hosting provider, such as Cloudflare Pages (Direct Upload) or GitHub Pages.

## Before publishing
Confirm the business address and Google Maps pin, phone number, menu availability and catering details with the restaurant owner.
